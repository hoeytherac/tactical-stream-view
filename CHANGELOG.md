# Changelog

## 1.0.2

- Fixed the ApplicationV2 settings window clipping the Save settings button on shorter screens.
- Made the settings body scrollable and kept the Save settings footer visible while scrolling.

## 1.0.1

- Added a dedicated same-origin browser-source launcher which completes Foundry's own sign-in flow.
- Added a locally stored Stream password field and an automatic-login source URL.
- Added a safe source URL which prompts for the Stream password inside Meld when needed.
- Migrated the Stream Connection settings window to Foundry's ApplicationV2 framework.
- Added a clear warning when the Meld browser layer is not configured as a readable 1080 × 1080 square.

## 1.0.0

- Added square tactical canvas, Dice So Nice stage, and right-side Living Journal chat rail.
- Added a permanent browser-source URL and dedicated Stream-user selection.
- Added live/standby broadcast state.
- Added directed GM camera following with composition-aware offset.
- Added one-click camera push and URL copy controls.
- Added connected-viewer heartbeat status.
- Added Foundry 13/14 chat rendering compatibility paths.
